# WA4: BTU Lab Website Redesign

This folder contains a six-page semantic HTML redesign of the ATLAS BTU Lab website.

## Pages

- `index.html` - Home and basic visitor information
- `tools.html` - All major tool areas, equipment, and training rules
- `people.html` - Current Spring 2026 staff plus the full emeritus/friends archive
- `visit.html` - Access, location, rules, policies, and safety reminders
- `events.html` - Calendar, orientations, and workshop proposals
- `faculty-support.html` - Faculty planning, instructional resources, social media, and giving

## Techniques Used

The project intentionally uses beginner-level HTML covered in class: document structure, headings, paragraphs, lists, links, images, relative paths, and semantic elements including `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`.

There is no CSS and no JavaScript because this assignment is about structure and meaning rather than visual design.

## Source Content

Content was reorganized and paraphrased from the current official BTU Lab pages, checked September 20, 2026:

- https://sites.google.com/view/btu-lab/home
- https://www.colorado.edu/atlas/btu-lab

The three local images are clearly labeled placeholders made for the class project. They can be replaced with approved official photographs later without changing the HTML structure.

## Open Locally

Open `index.html` in a browser. All page links and images use relative paths, so the site also works from a GitHub Pages folder.
