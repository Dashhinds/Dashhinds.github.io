What this is—and is not

This is an independently authored modern teaching model inspired by Melinda J. Menzer’s surviving Great Vowel Shift site. It is not the recovered Java applet. Its baseline plus eight steps reconstruct the legacy pedagogical sequence, not eight precisely dated or universally agreed historical events.

Method and preservation

Three tracks, kept deliberately separate

Modern teaching track

A dependency-free HTML, SVG, JavaScript, and Web Audio implementation that can run on GitHub Pages and be maintained with ordinary browser tooling.

Historical recovery track

A separate search for the original applet. In September 2026 its compiled classes, symbol images, and vowel recordings were recovered from the surviving Furman server and read statically; the Java source has not been found. Recovered material remains unpublished until rights and provenance are recorded.

Scholarly validation track

The sequence, trajectories, examples, notation, and acoustic targets need review by a historical linguist and phonetician before being presented as authoritative.
