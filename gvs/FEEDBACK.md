# Feedback on the Great Vowel Shift explorer

Feedback typed or dictated into the box at the bottom of https://dashhinds.github.io/gvs/ is sent
as a GitHub issue on this repository, labelled `gvs-feedback`:

https://github.com/Dashhinds/Dashhinds.github.io/issues?q=label%3Agvs-feedback

Nothing is collected silently. The page only opens GitHub's own issue form with the text filled in;
the person sending it presses GitHub's submit button, and GitHub asks them to sign in first.

## How feedback gets used

Open issues with that label are the queue. When one is acted on, add a line below and close the
issue with a link to the change.
